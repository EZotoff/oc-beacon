### §1.2 真机制框架：完结时 turn 内容槽销毁重建

三形态统一现象链（18:55 eof-fire 无 fire 轮 / 21:41 longpara 有 fire 轮 / §4 mock 振荡）：

```
完结事件链（part.updated end 帧 → message.updated completed → SseIdle → REST upsert:MergeStrategy）
```

- 无 fire 轮：整卡 4058→96→4120（d=-3962/+4024）；有 fire 轮：tail 槽 2212→96→回涨（d=-2116，#g 冻结片不受扰 cached=true）；mock 形态：完结多 publish 连发 → 每周期销毁一次 → tail 96↔158 六周期。

- **间歇性** = 完结链多结构 publish 与子树重建的竞态窗口（真模型 2/4；mock 高频连发时振荡多周期）。

### §1.3 DSH 免疫解释

DSH 完结走 `MessageIdSwapped` 单同步块换名 + 宿主前缀 part id（#509/#510 契约）——完结事件序列干净（无 part.updated end 全量替换帧、无紧随 REST upsert 的三连击），`pilotEverRendered` 跨完结存活（#510 pilot 即终态）。V1/V2 的完结是**多事件链**（权威 part 替换 + completed 翻转 + idle + REST 合并各发一次结构 publish），其中某一环使 turn 子树 remember 域销毁——精确触发输入待钉（§2 复现目标）。
